Typing Tutor(^_^)

A free, friendly touch-typing tutor that lives in your terminal. Learn to type without looking, one pair of keys at a time, then put it to work in a typing game that adapts to you.

what you get

  • A real course19 short lessons that start on the home row and add two keys at a time. Every exercise uses only keys you've already learned.
  • Never look downAn on-screen keyboard, coloured by finger, lights up the next key and tells you which finger to use.
  • Accuracy firstMistakes must be fixed before you move on. Lessons unlock at 95% accuracy plus a gentle speed goal.
  • Falling Words gameType letters and words before they hit the ground. It uses only your keys, starts at your pace, and speeds up as you level up.
  • Practice that targets youDrills for your weakest keys and for key pairs you keep mixing up, plus 1, 2 and 5 minute timed tests.
  • Type anythingPoint it at any text file (a book chapter, an article) and work through it. Your place is remembered.
  • QWERTY, Dvorak, ColemakEach has its own course. Learn Dvorak or Colemak without changing your computer's settings.
  • Everyone gets a profileShare one computer: each person has their own lessons, stats and high scores.
  • A tiny friendAn ASCII mascot cheers you on ♪(^_^)♪, winces at typos (>_<) and naps when you pause (˘_˘)zzZ.

install

Typing Tutor is a single Python file with nothing else to install on macOS and Linux (Windows needs one small extra package). You need Python 3.10 or newer and a terminal window at least 60×20 characters.

Windows 10 / 11

  1. Install Python from python.org. In the installer, tick "Add python.exe to PATH". Or, in a terminal: 
    winget install Python.Python.3.13
  2. Open Windows Terminal (search for "Terminal" in the Start menu) and add curses support, which Python on Windows doesn't include: 
    py -m pip install windows-curses
  3. Download Typing Tutor: 
    curl.exe -o typing_tutor.py https://raw.githubusercontent.com/mojeska/typingtutor/main/typing_tutor.py
  4. Start it: 
    py typing_tutor.py

Tip: use Windows Terminal rather than the old "Command Prompt" window, so the colours, box lines and mascot faces all show up properly.

macOS

  1. Open Terminal (Applications → Utilities) and check your Python: 
    python3 --version
    If it says 3.10 or higher, skip to step 3. The Python that comes with macOS is usually 3.9, which is too old.
  2. Get a newer Python, either with Homebrew: 
    brew install python
    or with the installer from python.org. Then open a new Terminal window.
  3. Download Typing Tutor: 
    curl -O https://raw.githubusercontent.com/mojeska/typingtutor/main/typing_tutor.py
  4. Start it: 
    python3 typing_tutor.py

Linux

  1. Python 3.10+ is already installed on almost every current distribution. To check: 
    python3 --version
  2. Download Typing Tutor: 
    curl -O https://raw.githubusercontent.com/mojeska/typingtutor/main/typing_tutor.py
  3. Start it: 
    python3 typing_tutor.py
  4. Optional: make it a command you can run from anywhere as typing-tutor: 
    install -Dm755 typing_tutor.py ~/.local/bin/typing-tutor

Prefer git? git clone https://github.com/mojeska/typingtutor.git works on all three. To update later, just download the file again. Your progress is stored separately and is kept.

first steps

When it starts, type your name to make a profile, then pick Continue: lesson 1. Rest your index fingers on the bumps on F and J and follow the highlighted keys.

↑ ↓ or j kmove around menus
Enterchoose / start
Escgo back (or pause the game)
--user NAMEstart straight into your profile, e.g. python3 typing_tutor.py --user Sam

Progress is saved automatically in your home folder under .local/share/typing-tutor.
